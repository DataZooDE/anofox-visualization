[anofox-optimize](https://github.com/DataZooDE/anofox-optimize) — packing, assignment, waves, sequencing with changeovers, knapsack and assortment selection, scheduling and replenishment — solvers callable from SQL.

```sql
INSTALL anofox_optimize FROM 'https://get.erpl.io';   -- duckdb -unsigned
LOAD anofox_optimize; LOAD anofox_visualization;
```

## Plot its results

The solvers return a STRUCT of lists per instance. Unnest the plan into one row per item, and the decision views draw it:

| Output | Plotted by |
|---|---|
| bin packing, waves (`pack_*`, `wave_*`) | `anofox_plot_assignment`: items stacked per bin against the capacity |
| knapsack, assortment | `anofox_plot_selection`: picked items first |
| sequencing (`opt_sequence_by`) | `anofox_plot_sequence`: cumulative setup by position |
| scheduling | `anofox_plot_schedule`: a Gantt per resource, late tasks marked |
| objectives per algorithm | `anofox_plot_summary` |

`anofox_plot(t)` picks the macro from the table's columns. The macros are aggregates: `GROUP BY` gives one SVG per group.
