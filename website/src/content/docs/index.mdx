## SQL in, dashboard out

```sql
SELECT 'Revenue by channel'::TITLE;
SELECT week::XAXIS, channel::CATEGORY, sum(revenue)::BARCHART_STACKED
FROM sales GROUP BY ALL ORDER BY week;

SELECT sum(revenue)::MONEY, 'Revenue'::LABEL,
       sum(revenue) - sum(revenue_prev)::DELTA FROM sales;
```

Each `SELECT` is one panel. The casts say what a column is for: `::XAXIS`, `::CATEGORY` and a chart kind (`::BARCHART_STACKED`) make a chart, `::MONEY` + `::DELTA` a KPI tile with its change. Inputs (`::DROPDOWN`, `::PERIOD`), tabs, drill-downs and cross-filters are roles too — [241 of them](https://github.com/DataZooDE/anofox-visualization/blob/master/docs/DOCS.md), checked by `dashboard --check`.
