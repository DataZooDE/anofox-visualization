## From one line to an application

<p class="lp-lead">Start with a single chart. Every step below adds a few lines to the same file — nothing has to be rewritten when it grows.</p>

<div class="lp-step">
<div class="lp-step-text">
<span class="lp-num">1</span>
### A chart is one `SELECT`

The cast on the measure picks the chart; the other columns say where each row goes. Sort and aggregate in SQL — the chart draws what the query returns.

```sql
SELECT region ::XAXIS, sum(revenue) ::BARCHART,
       'North leads, South close behind'::TITLE
FROM sales GROUP BY ALL ORDER BY 2 DESC;
```

### A dashboard is a few more

KPI tiles with change, trend line and goal; a 12-column grid; boxes, tabs and sections — each a statement of its own.

```sql
SELECT 'Headline'::GROUP;
SELECT sum(revenue) ::MONEY, 'Revenue'::LABEL,
       sum(revenue_prev) ::DELTA,
       list(r ORDER BY week) ::SPARKLINE FROM …;
SELECT 1::ENDGROUP;
SELECT 8::COL;
SELECT week ::XAXIS, channel ::CATEGORY,
       revenue ::AREACHART_STACKED FROM sales;
```

### Interaction is variables

An input's column name is a DuckDB variable. Clicks set variables too: cross-filter, named selections, row selection, and drill-down through any hierarchy — on bars, maps and treemaps.

```sql
SELECT 'geo: country > state > district'::DRILL;
SELECT code ::REGION, name ::LABEL, revenue ::BARCHART,
       'quantile 5'::CLASSES
FROM rm_level()             -- reads getvariable('country'), …
ORDER BY revenue DESC;
```

### Forecasts and models, in the same SQL

Load an anofox extension and plot its results: forecasts with nested interval fans, backtests, regression forests, survival curves, optimiser plans. Here: next week's load per substation, three methods backtested, against firm capacity.

```sql
LOAD anofox_forecast;
CREATE TABLE fc AS
SELECT * FROM ts_forecast_by('load', substation, ds, mw, 'MSTL',
  168, '1h', MAP{'seasonal_periods': '[24,168]'});
SELECT ds ::XAXIS, yhat ::LINECHART,
       yhat_lower ::BAND_LOWER, yhat_upper ::BAND_UPPER,
       firm_mw ::REFLINE,
       'firm capacity' ::REFLINE_LABEL
FROM fc JOIN substations USING (substation)
WHERE substation = getvariable('substation');
```

<span class="lp-num">5</span>
### Ship it — to a page, a server or an agent

The same file renders to HTML and SVG in CI, publishes as a static site, or runs on a **locked, read-only server** with login, row and column policies, scheduled reports and alerts. A dashboard's `-- @question` lines can be answered over **REST and MCP** for the signed-in caller.

```sh
dashboard --check sales.sql --strict     # lint in CI
dashboard --site dashboards/ public/     # a static site
serve --dashboards dashboards/ \
      --db sales.duckdb --options locked.json
```
